# Support

## Questions and setup help

Search existing issues first. If the documentation and existing issues do not
answer your question, open a **usage question** with the issue form.

Include:

- the commit or version you are running;
- your operating system and Python version;
- the command that failed and its redacted output; and
- the relevant configuration **names**, with all values and credentials removed.

This is a single-maintainer project with no guaranteed response time or
service-level agreement. The maintainer cannot provide support for third-party
accounts, billing, telephony provisioning, or legal compliance.

GitHub Discussions are not enabled. Please use issues.

There is no public support email. Do not send production secrets or live-call
artifacts to a guessed address.

## Bugs and feature requests

Use the bug-report and feature-request forms. Never include API keys, bearer
tokens, phone numbers, call transcripts, or other personal data.

## Security vulnerabilities

Do not open a public support issue for a suspected vulnerability. Follow
[SECURITY.md](SECURITY.md).
