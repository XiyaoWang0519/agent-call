# Support

## Questions and setup help

Search existing issues first. If the documentation and existing issues do not
answer your question, open a new issue with:

- the commit or version you are running;
- your operating system and Python version;
- the command that failed and its redacted output; and
- the relevant configuration names, with all values and credentials removed.

This is a community-maintained project with no guaranteed response time or
service-level agreement. The maintainer cannot provide support for third-party
accounts, billing, telephony provisioning, or legal compliance.

## Bugs and feature requests

Use the repository's bug-report and feature-request templates. Never include
API keys, bearer tokens, phone numbers, call transcripts, or personal data.

## Security vulnerabilities

Do not open a public support issue for a suspected vulnerability. Follow the
private reporting process in [SECURITY.md](SECURITY.md).
